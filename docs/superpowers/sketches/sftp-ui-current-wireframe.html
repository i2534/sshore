⑤ 我对着实拍看到的可疑点（只记录，未改任何代码）

  1. ③ 列头被压变形：1044px 窗口下「名称 ▲」换 3 行、过滤框被拉成 44px 高，行高 49px；同样一行的「大小/修改时间」却是单行右对齐。
  2. ② 面板头过挤：7 个元素挤一行，路径框（唯一能看清“我在哪”的控件）被压到最短；窗口再窄还会继续挤。
  3. ② 计数重复：「84 项」与「已选 0 项 ▾」语义相近、紧挨在一起，0 选中时也留着一个菜单入口。
  4. ③ 过滤框位置：坐在表头行右侧，与「大小/修改时间」没有列对齐关系，用户难判断它过滤的是“当前列”还是“整个列表”。
  5. ⑧ 位置弹层遮挡：260px 固定宽、盖住整个左侧面板；长路径横向滚动，最近列表和收藏挤在同一柱里。
  6. ⑤ 队列位置：夹在两面板与日志之间，空态也占一行；任务多时上限 140px 会滚动。
  7. ⑦ 日志面板：固定 140px，窗口最大化也不变高；chips 行出现/消失时过滤栏会整体上下跳。
  8. 整体中英混排：按钮中文、日志正文英文、过滤占位符 filter source_id (规则名/主机)；深浅主题都跟随系统（theme: system）。
